# 전주 비빔핏 (Jeonju BibimFit)

> **"전주의 모든 운동을 한 그릇에 비벼 담다"**
> 전주 지역 밀착형 스포츠 통합 플랫폼 · **Phase 1 MVP**
> _(구 프로젝트명: 플레이패스 / PlayPass — 저장소·코드 식별자는 유지)_

에어로빅부터 주짓수까지 전주 전역의 운동 시설을 앱 하나로 **비교 · 예약 · 등록**하고,
우리 동네 특가·크루까지 연결하는 로컬 스포츠 생태계 플랫폼입니다.

## 빠른 시작

의존성 설치가 필요 없습니다. Node.js 18+ 만 있으면 됩니다.

```bash
node server.js
# 또는
npm start
```

- **미리보기(데스크톱)**: <http://localhost:3000/> — 스마트폰 프레임 안에서 앱을 체험
- **사용자 앱**: <http://localhost:3000/app>
- **파트너(시설 관리자) 앱**: <http://localhost:3000/partner>

시드 데이터로 초기화하려면:

```bash
npm run seed   # data/db.json 을 seed.json 기준으로 재설정
```

> 📱 **스마트폰 미리보기** — 데스크톱(가로 900px↑)으로 `/` 에 접속하면 실제
> 스마트폰 목업(프레임) 안에 앱이 iframe으로 들어가, 폰에서 어떻게 보이는지
> 바로 확인할 수 있습니다. 왼쪽 패널에서 **사용자 앱 / 파트너 앱**을 전환합니다.
> 실제 스마트폰으로 접속하면 미리보기 없이 앱이 바로 실행됩니다.

## 앱 구조 (경로 최적화)

야놀자식 심플 구조로, 사용자 앱은 **하단 4개 탭**으로 정리했습니다.

| 탭 | 역할 |
| --- | --- |
| 🏠 **홈** | 지역 선택 · 검색 · 종목 아이콘 · 마감임박 특가 · 우리 동네 추천 |
| 🧭 **탐색** | 종목/지역 필터 · 정렬(후기·가격·거리) · 시설 리스트 |
| 🧩 **허브** | 원데이 클래스 · 크루 매칭 · 용품 대여 (+ 오픈 예정 웰니스) |
| 👤 **마이** | 내 수강권 · 예약 · 크루 (닉네임 기반) |

핵심 동선은 **홈(종목/특가/추천) → 상세 시트 → 결제·예약** 으로 짧게 유지되며,
시설 상세·허브 상품은 하단에서 올라오는 **바텀시트**로 열립니다. 파트너 앱은
소비자 탭과 분리해 마이 탭·미리보기에서 진입합니다.

## 배포 (Vercel)

서버리스로 동작하도록 구성되어 있어 **별도 설정 없이** 바로 배포됩니다.

**방법 1 — GitHub 연동 (권장)**
1. [vercel.com](https://vercel.com) 로그인 → **Add New → Project**
2. 이 저장소를 Import (Framework Preset은 **Other**로 자동 인식)
3. 그대로 **Deploy** → 발급되는 `https://<프로젝트>.vercel.app` 을 휴대폰에서 열기

**방법 2 — CLI**
```bash
npm i -g vercel
vercel        # 미리보기 배포
vercel --prod # 프로덕션 배포
```

동작 구조:
- 정적 화면(`public/`)은 Vercel 정적 호스팅으로 서빙
- 모든 `/api/*` 요청은 서버리스 함수 `api/index.js` 가 처리 (로컬 `server.js` 와
  동일한 `src/router.js` 를 공유)
- `vercel.json` 이 라우팅(정적 ↔ API)을 정의

> ℹ️ 서버리스 환경은 파일시스템이 읽기 전용이라, 결제·예약·출석 등 **쓰기 데이터는
> 함수 인스턴스 메모리에 유지**되며 일정 시간 후(콜드 스타트) `seed.json` 기준으로
> 초기화됩니다. 기능 시연·확인용으로는 충분하며, 실서비스 전환 시 이 지점에
> 실제 DB(Postgres/KV)를 연결하면 됩니다.

## 구현된 핵심 기능 (Phase 1)

### A. 사용자 앱 (User App)
- **종목별 필터링** — 클라이밍·크로스핏·주짓수·복싱·헬스·필라테스·에어로빅·스포츠댄스·요가·테니스·수영·스크린골프 (12종)
- **지역 큐레이션 (구·동 세분화)** — 전주를 완산구/덕진구, 핵심 존 4개로 쪼개 타깃 페르소나별 큐레이션
- **위치 기반 검색 / 정렬** — 거리순(Haversine) · 가격순 · 후기순, 브라우저 위치 또는 전주 주요 지점 선택
- **마감 임박 특가** — 시설 유휴 시간대 인벤토리를 할인율 순으로 노출 (야놀자식 yield 관리)
- **시설 상세 페이지** — 시설 소개, 가격표(상세 비교), 강사 프로필, 실시간 수용 인원
- **결제 및 수강권 등록** — 요금제 결제 → 수강권 발급(프로모션 할인 자동 적용)
- **클래스 예약** — 실시간 잔여 좌석 확인 및 예약
- **연령별·지역별 맞춤 추천** — 연령대 + 선호 종목 + 위치 + 지역 존 큐레이션 기반 개인화

### B. 파트너 앱 (Partner / Gym App)
- **실시간 예약 · 출석 관리 대시보드** — 예약 현황 및 출석 체크 토글
- **프로모션 툴** — 타임세일 · 신규 가입 이벤트를 시설이 직접 등록/중지
- **통계 분석** — 요일별 / 시간대별 이용률, 수용률, 누적 매출, 수강권 판매 현황

### C. 비빔핏 허브 (Hub · 모듈형 플러그인)
공간 → 경험 → 커머스 → 웰니스로 확장하는 허브. 새 로컬 서비스는 플러그인 파일 하나로 붙습니다.
- **원데이 스포츠 클래스** (experience) — 등록 없이 한 번 참여하는 클래스 예약
- **동호회 크루 매칭** (experience) — 지역·종목별 크루 가입
- **스포츠 용품 대여** (commerce) — 장비 대여/커머스
- **(오픈 예정)** 로컬 샐러드 정기배송 · 물리치료/마사지 · 지역 건강검진 연계 (wellness)

## 지역 세분화 & 존 큐레이션 전략

| 존 | 구 | 핵심 동 | 타깃 | 큐레이션 종목 |
| --- | --- | --- | --- | --- |
| 효자동 신시가지 | 완산구 | 효자동 | 2030 MZ | 클라이밍·크로스핏·주짓수·필라테스 |
| 삼천·서신 생활권 | 완산구 | 삼천·서신동 | 4060 | 에어로빅·스포츠댄스·수영·스크린골프 |
| 송천 에코시티·혁신도시 | 덕진구 | 송천·만성동 | 3040 패밀리 | 요가·테니스·필라테스·수영 |
| 전북대 상권 | 덕진구 | 덕진·금암동 | 대학생 | 헬스·주짓수·복싱·클라이밍 + 마감임박 특가 |

데이터는 `city(전주시) > district(구) > neighborhood(동)` + `zone`으로 매핑되어(`src/regions.js`),
존 선택 시 추천 알고리즘이 해당 존의 타깃 페르소나·추천 종목에 가중치를 부여합니다.
`/app?zone=jbnu&tab=explore` 처럼 존·탭을 URL로 공유할 수 있습니다.

## 아키텍처

Phase 3(구독형 짐플릭스 모델)로의 전환을 염두에 두고 **모듈화된 계층 구조**로 설계했습니다.

```
PlayPass/
├── server.js          # 로컬 개발 서버 (정적 서빙 + /api, 무의존성)
├── api/index.js       # Vercel 서버리스 함수 (/api/* 위임)
├── vercel.json        # 배포 라우팅 (정적 ↔ API)
├── src/
│   ├── router.js      # 공용 API 디스패처 (server.js·api/index.js 공유)
│   ├── db.js          # 데이터 스토어 (로컬=파일 / 서버리스=인메모리 폴백)
│   ├── regions.js     # 전주 지역 세분화(city>district>zone) + 존 큐레이션 규칙
│   ├── logic.js       # 도메인 로직: 거리·정렬·추천(존 가중)·통계·마감임박 특가
│   ├── api.js         # REST API 핸들러 (뷰와 무관한 순수 로직)
│   └── plugins/       # 허브 플러그인 (모듈형 확장)
│       ├── registry.js            # 플러그인 로더/디스패처
│       ├── experiences/           # oneday · crew · rental
│       └── wellness/planned.js    # 오픈 예정 서비스(샐러드/물리치료/건강검진)
├── data/
│   ├── seed.json      # 전주 시설 16곳 시드 (지역/존/유휴특가 매핑)
│   └── reset.js       # 시드 초기화 스크립트
└── public/            # 프론트엔드 (야놀자풍 모바일 UI)
    ├── preview.html                 # 데스크톱 스마트폰 미리보기(showcase)
    ├── app.html · js/app.js         # 사용자 앱 (홈/탐색/허브/마이 4탭)
    ├── partner.html · js/partner.js # 파트너 앱
    └── css/style.css
```

- **데이터 계층 분리**(`db.js`)로 향후 PostgreSQL 등 실 DB 교체가 용이합니다.
- **API 핸들러가 순수 함수**(`{status, body}` 반환)라 서버/서버리스 어디든 이식 가능합니다.
- **추천/통계 로직 독립 모듈**(`logic.js`)은 추후 AI 기반 루틴 추천으로 확장할 지점입니다.
- **허브 플러그인 아키텍처**(`src/plugins/`) — 새 로컬 서비스는 `registry.js`에 import 한 줄만
  추가하면 `/api/hub/*`로 자동 노출됩니다. 야놀자가 레저·카셰어링을 붙인 방식과 동일합니다.

## API 요약

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| GET | `/api/meta` | 종목 카테고리 · 연령대 · 지역 트리 메타 |
| GET | `/api/regions` | city > district > zone 지역 트리 |
| GET | `/api/facilities?category=&sort=&lat=&lng=&q=&zone=&district=&neighborhood=` | 시설 목록(필터/정렬/검색) |
| GET | `/api/facilities/:id` | 시설 상세 + 활성 프로모션 |
| GET | `/api/recommend?ageGroup=&categories=&lat=&lng=&zone=` | 연령별·지역별 맞춤 추천 |
| GET | `/api/deals?zone=` | 마감 임박 특가(유휴 인벤토리) |
| POST | `/api/checkout` | 수강권 결제/등록 |
| POST | `/api/reservations` | 클래스 예약 |
| GET | `/api/passes?user=` | 내 수강권 조회 |
| GET | `/api/my?user=` | 마이 탭 집계(수강권+예약+크루) |
| GET | `/api/hub` | 허브 플러그인 목록 |
| GET | `/api/hub/:id/catalog?zone=&category=` | 플러그인 카탈로그 |
| POST | `/api/hub/:id/:action` | 플러그인 액션(book/join/rent) |
| GET | `/api/partner/:id/dashboard` | 파트너 대시보드 데이터 |
| POST | `/api/partner/checkin` | 출석 체크 토글 |
| POST | `/api/partner/promotions` | 프로모션 등록 |
| POST | `/api/partner/promotions/:id/toggle` | 프로모션 활성/중지 |

## 로드맵

- **Phase 1 (현재)** — 전주 주요 시설 가격 비교 / 예약 / 등록 플랫폼 ✅ MVP
- **Phase 2** — 운동 후기, 크루 매칭 등 소셜/커뮤니티 기능
- **Phase 3** — '비빔핏 멤버십' 구독형 모델(짐플릭스), 통합 포인트 관리

## 참고

- 시연용 MVP로, 결제는 실제 PG 연동 없이 등록 처리만 수행합니다.
- 런타임 데이터는 `data/db.json`(gitignore)에 저장되며 `npm run seed`로 초기화됩니다.
